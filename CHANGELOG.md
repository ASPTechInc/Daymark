# [v1.0](https://github.com/ASPTechInc/Daymark/tree/v1.0) (2026-08-24)

Full stable release of Daymark, a privacy-first day-counter application for Android.

### Features

* **Activity tracking**: Create and manage milestones, activities, events and reminders.
* **Home screen widgets**: Added 1x1 "Quick Add" and 4x4 "Activities List" widgets for immediate
  access and viewing.
* **Device notifications**: Real-time notifications when an activity reaches its end date (can be
  toggled in Settings).
* **Relative time display**: Human-friendly elapsed or remaining time (e.g., "3 weeks ago", "in 2
  months").
* **Rich management**: Quickly edit, duplicate, delete, archive and Share activities.
* **Organisation**: Organise data using categories and tags with manual drag-and-drop
  reordering.
* **Discovery**: Powerful search, filtering (by category, year and month) and sorting (alphabetical
  and by start date).
* **Data sovereignty**: Export activities to both JSON (for backup) and human-readable CSV
  formats.
* **FOSS Readiness**: Integrated open source Fastlane-compatible metadata for F-Droid submission.
* **Security**: Privacy lock with App PIN support to keep milestones secure.
* **Modern UI**: Full Material 3 interface with support for Dynamic Colour theming (
  Light/Dark/System).
* **Developer experience**:
    * Automated CI/CD via GitHub Actions for build verification.
    * Comprehensive logging and KDoc documentation for contributors.
    * Standardised layout and resource naming conventions.
* **Onboarding**: Sample activities included on first app launch to help you get started.
