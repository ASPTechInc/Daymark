# [v1.0](https://github.com/Sherida101/Daymark/tree/v1.0) (2026-08-16)

Initial stable release of Daymark, a modern day-counter application for Android.

### Features

* **Activity Tracking**: Create and manage milestones, events, and reminders.
* **Date Range Support**: Optional end dates to track specific durations alongside ongoing events.
* **Relative Time Display**: Human-friendly elapsed or remaining time (e.g., "3 weeks ago", "in 2
  months").
* **Rich Management**: Quickly Edit, Duplicate, Reset, Delete, Archive, and Share activities.
* **Organisation**: Organise your data using Categories and Tags.
* **Discovery**: Powerful Search, Filtering (by category and month), and Sorting (alphabetical and
  by start date).
* **Modern UI**: Full Material 3 interface with support for Dynamic Colour theming.
* **Security**: Privacy Lock with App PIN support to keep your milestones secure.
* **Data Management**:
    * Persistent storage using Android SharedPreferences.
    * Backup & Restore via JSON export/import (Save to Device).
* **Onboarding**: Sample activities included on first launch to help you get started.
